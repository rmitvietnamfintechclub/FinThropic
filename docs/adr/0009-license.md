# 0009 Licence: MIT (to confirm)

Status: proposed
Date: 2026-11-15   Decided by: Project Leader, to confirm with the Head of Technology

## Context
A repository without a licence is not open source: nobody may legally reuse it. The repository may be made public after development. If we copy code from another project (for example T3 Code, MIT, in the PBI-011 trial), we must keep its notice.

## Options
1. MIT: short, permissive, common for student and club projects.
2. Apache 2.0: permissive with a patent grant; longer.
3. No licence while the repository is private: nothing to decide now, but it must be settled before it is public.

## Decision
Proposed: MIT, copyright "RMIT Vietnam FinTech Club". No `LICENSE` file until the Head of Technology confirms.

## Consequences
After confirmation: `LICENSE` at the root and status accepted. A `THIRD_PARTY_NOTICES.md` is added if any code is copied from another project.
